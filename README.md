# UNDEFINED_GAME

A small **Metroidvania-style game project** created by [iansuassuna](https://github.com/iansuassuna) during childhood.

## About

UNDEFINED_GAME is an experimental 2D game project built with GameMaker. The repository contains the project definition along with its game objects, rooms, scripts, sprites, and configuration files.

This project is preserved as a snapshot of an early game-development experiment.

## Project structure

- `Metrovania.yyp` — GameMaker project file
- `objects/` — Game objects and their events
- `options/` — Project configuration
- `rooms/` — Game rooms and level layouts
- `scripts/` — Reusable game logic
- `sprites/` — Visual assets

## Opening the project

1. Install a compatible version of [GameMaker](https://gamemaker.io/).
2. Clone this repository:

   ```bash
   git clone https://github.com/iansuassuna/UNDEFINED_GAME.git
   ```

3. Open `Metrovania.yyp` in GameMaker.
4. Run the project using GameMaker's **Run** button.

Because this is an older project, some files or features may require adjustments to work with current versions of GameMaker.

## Status

This is a personal archival project and is not currently under active development.
